# Publish NWL in about five minutes

1. Download `NWL_GitHub_Vercel_Ready.zip` and extract it.
2. Create a repository on GitHub (for example `nwl-website`).
3. Choose **Add file → Upload files**. Select **all extracted files and the assets folder contents**; make sure `index.html` is in the root of the repository, not inside an extra `NWL_GitHub_Vercel_Ready/` directory.
4. Open https://vercel.com/new → **Import Git Repository** → select your repository.
5. Use **Other** as framework, root `./`, no build command, and press **Deploy**.
6. Your site appears at the generated `*.vercel.app` address. To update the site later, commit edits to GitHub.

**Important:** This is a visual/interactive frontend only. The on-page challenge brief does not submit information to you.
